# 鬼趴 PEEK 训练舱

一个运行在浏览器里的身法输入节奏训练器，用于练习《三角洲行动》玩家常说的“鬼趴 PEEK”动作。

项目把动作拆成 **游龙步、断趴、视角错位、探身或闪身** 四个阶段，通过第一人称掩体场景、时间窗口和实时提示，让玩家可以脱离实战反复练习按键节奏，观察自己何时处于掩体后、何时暴露在敌方直架枪线上。

无需安装依赖。直接打开 `index.html` 即可使用。

## 功能

- **自由操作**：随意移动、趴伏、探身和横移，不判定顺序，不会因为操作失误中断。
- **跟随指令**：按提示完成动作链，训练器会检查顺序、方向、响应和停留时间。
- **两种出掩体方式**：支持 `E/Q` 探身，也支持 `A/D` 横移闪身。
- **第一人称训练场景**：包含己方掩体、对面掩体、直架敌人和武器视图。
- **暴露状态反馈**：横移或探身后会显示敌方枪线锁定、画面边缘警告和接触状态。
- **三档判定**：入门、标准、极限，适用于不同熟练度。
- **45 秒挑战**：连续完成动作链，统计得分、成功率、连击和历史最佳。
- **桌面与移动端**：桌面使用键盘，手机端提供触控按键。
- **本地记录**：设置和最佳成绩保存在浏览器本地存储中。
- **无后端**：没有构建步骤、账号系统或数据上传。

## 快速开始

### 直接打开

下载项目后双击：

```text
index.html
```

页面会直接在浏览器中运行。

### 使用本地静态服务器

如果浏览器限制了本地文件功能，可以在项目目录启动任意静态服务器：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

项目也可以直接部署到 GitHub Pages。入口文件为 `index.html`，不需要额外构建。

## 操作方式

| 操作 | 默认键位 | 说明 |
| --- | --- | --- |
| 移动 | `W A S D` | 自由模式可持续移动 |
| 游龙步 | `W + Shift` | 指令训练的起手动作 |
| 趴伏 | `Z / C` | 自由模式再次按下可起身 |
| 断趴 | `Shift` | 趴伏前段松开再按 |
| 探身 | `E / Q` | 右探或左探，松开完成回位 |
| 闪身 | `A / D` | 右移或左移出掩体 |

页面中的键位是练习映射。实际游戏内请根据自己的键位设置对应。

## 两种训练模式

### 自由操作

默认进入自由操作模式。

- 可以随意移动、趴伏、探身和横移。
- 不会触发超时、顺序错误或停留时长判定。
- 适合熟悉场景、测试掩体位置并观察横移与暴露关系。
- 敌方状态、枪线和 HUD 仍会实时更新。

### 跟随指令

选择“跟随指令”或开始 45 秒挑战后，训练器才会按提示进行判定。

1. 按住 `W + Shift` 进入游龙步。
2. 按 `Z` 或 `C`，进入趴伏前段。
3. 松开 `Shift`，再按一次完成断趴。
4. 进入 GHOST 窗口后，按提示向指定方向探身或闪身。
5. 在时间窗口内松开按键，回到掩体。

指令训练会左右交替提示方向。探身方式可以在 `E/Q` 与 `A/D` 之间切换。

## 判定难度

| 难度 | 断趴窗口 | 探身响应 | 建议停留 |
| --- | --- | --- | --- |
| 入门 | 260-1000 ms | 1200 ms 内 | 180-800 ms |
| 标准 | 160-650 ms | 800 ms 内 | 160-620 ms |
| 极限 | 110-430 ms | 520 ms 内 | 120-460 ms |

建议先固定动作顺序，再逐步缩短断趴与探身之间的间隔。

## 画面反馈

训练画面会同步显示：

- 当前姿态与镜位
- 横移距离
- 断趴耗时
- 探身响应时间
- 探身停留时间
- 敌方直架状态
- 是否离开掩体
- 当前动作链与最近输入

敌人始终处于直架状态。玩家横移或探身离开掩体后，HUD 会切换为“枪线锁定”，画面边缘也会出现暴露提示。

## 自定义

- 判定窗口：修改 `app.js` 中的 `difficulties`。
- 默认提示与文案：修改 `index.html`。
- 颜色、间距与主题：修改 `styles.css` 中的 CSS 变量。
- 掩体、敌人和枪线：修改 `app.js` 中的 Canvas 绘制函数。

项目没有第三方运行依赖，使用原生 HTML、CSS、JavaScript 和 Canvas。

## 机制边界

这是一个独立的按键节奏训练页面，不读取游戏进程，不注入游戏，也不自动发送输入。

- 页面模拟的是动作顺序、时间窗口和暴露状态。
- 页面不代表官方动作判定、受击框或网络表现。
- 不同版本、网络延迟、角色姿态和服务端同步都可能改变实战手感。
- 动作解释参考公开视频和评论区讨论，最终效果请以游戏训练场及当前版本实测为准。

本项目与腾讯、天美工作室群及《三角洲行动》官方无关联。
